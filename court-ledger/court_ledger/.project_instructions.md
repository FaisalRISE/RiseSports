# Court Ledger — Project Notes

## Overview
Mobile-first sports group finance app (like Cashbook for badminton crews). Books → Members → Activities (equal split) → Payments (two-party acknowledgement: payer marks paid, recipient confirms; only CONFIRMED payments affect balances). Amounts stored in paise (Int), formatted ₹ en-IN, timezone Asia/Kolkata.

## User decisions (do not re-ask)
- Email/password login (not OTP). Public /signup exists.
- RBAC per book: PRIMARY_ADMIN & BOOK_ADMIN see ALL pairwise balances; DATA_OPERATOR sees own balance + own pairs, can edit own entries; VIEWER sees own net only, read-only. Enforced at API layer (balances/pairs stripped in /api/books/[bookId] response by role).
- Theme: dark default (navy #060a12 bg, lime #a3e635 primary, teal #2dd4bf accent) with light toggle on Profile. User said "will refine theme later" — expect future theme iteration.

## Architecture
- Finance engine: lib/finance.ts (pure; calcShares remainder→payer, calcPairs, calcSettleUp min-transactions, calcLedgerFor running balance, formatMoney). RBAC helpers: lib/rbac.ts. Server helpers: lib/server-helpers.ts (getMembership with email fallback auto-link).
- Layout: app/(app)/layout.tsx auth-guards + BottomNav (Home/Books/Activity/Profile), max-w-600px, pb-24. Default home = /overview (My Overview: grand total, per-person consolidated across books, book cards, pending acks).
- Book detail tabs: Entries / Balances / Members / Reports; vaul Drawer bottom sheets for forms; FAB Add Entry.
- Fonts: Sora + JetBrains Mono. Semantic tokens in globals.css incl. --positive/--negative/--hero-from/to; utilities .hero-card, .tabular.
- Seed: scripts/seed.ts seeds hidden test account + "Badminton Crew" demo book (idempotent, no deletes).

## Gotchas
- batch_file_write cannot create dirs with parens `(app)` — use bash mkdir/heredoc.
- eslint.ssr.config.mjs blocks `new Date()` in useState initializers — init empty and set in useEffect.
- ActivityType enum: COURT_BOOKING, EQUIPMENT, FOOD_DRINKS, OTHER. User model field is passwordHash.
